About

An unofficial, non-commercial fan reference for MHGU's armour skills. Each skill shows the game's own description, then a detailed explanation: the exact amounts, what counts, the limits per weapon and how it stacks with other skills.

Where the numbers come from: read from the game's own code and data, not from guides. Where something isn't confirmed yet, the skill says so.

Development: Built by the author with substantial help from Claude Code, Anthropic's AI coding tool, reviewed and directed by the author.

Menu textures and font: carried over from the sibling MHGU apps.
